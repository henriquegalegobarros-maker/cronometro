⏱️ Cronômetro

Projeto desenvolvido durante meus estudos de programação, com o objetivo de praticar os fundamentos de HTML, CSS e JavaScript.

🚀 Funcionalidades

Iniciar o cronômetro.

Pausar a contagem do tempo.

Zerar o cronômetro.

Exibir horas, minutos, segundos e centésimos.

Efeitos visuais nos botões ao passar o mouse e ao clicar.

🛠️ Tecnologias utilizadas

HTML5: estrutura da página.

CSS3: estilização, posicionamento dos elementos e efeitos visuais.

JavaScript: lógica do cronômetro, controle do tempo e interação com os botões.

💻 O que pratiquei neste projeto

Seleção de elementos com querySelector().

Manipulação do conteúdo com innerHTML.

Eventos com addEventListener().

Funções JavaScript.

Controle de tempo com setInterval() e clearInterval().

Manipulação de classes com classList.add() e classList.remove().

Utilização de Date.now() para calcular o tempo.

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento web. Foi desenvolvido para colocar em prática os conhecimentos adquiridos em JavaScript, HTML e CSS.
